Windows 10 / 11 常用快捷键速查

按「系统功能」分类整理的系统级快捷键，覆盖开始菜单、窗口贴靠、资源管理器、虚拟桌面、截图录屏、输入法与终端。Win11 新增或行为有变化的条目都标了「Win11」，笔记本请先确认 Fn Lock。

先记住 6 条规律

快捷键不是靠死记，记住下面几条规律，大部分组合键都能推出来。

1Win 键是系统总开关

单按开「开始」；Win+S 搜索、Win+E 资源管理器、Win+I 设置、Win+X 快速菜单；Win+方向 贴靠；Win+数字 打开任务栏第 N 个应用。

2Ctrl 管文档内，Alt 管窗口与菜单

Ctrl+C/V/Z/S 在应用内部生效；Alt+Tab 切窗口、Alt+F4 关窗口、Alt+Space 开窗口菜单；对话框里 Alt+字母 直接触发带下划线的按钮。

3Shift 表示反向、扩展、加强

Alt+Shift+Tab 反向切窗口；Shift+Delete 永久删除；Shift+方向键 选择；Win+Shift+S 截区域；Win+Shift+←/→ 把窗口扔到另一台显示器。

4Win+方向键是贴靠，两两组合成四分屏

Win+← 再 Win+↑ = 左上角；Win+Alt+↑/↓（Win11）直接贴上半屏/下半屏；Win+Z 打开贴靠布局，鼠标悬停最大化按钮也能选。

5数字键对应任务栏位置

Win+1…9 打开/切换；Shift 开新实例；Ctrl 切到该应用最近窗口；Ctrl+Shift 以管理员启动；Win+Alt 打开跳转列表。

6Win+Ctrl 与虚拟桌面，Win+Alt 与显示/声音

Win+Ctrl+D 新建桌面、Win+Ctrl+←/→ 切换、Win+Ctrl+F4 关闭；Win+Alt+B 开关 HDR、Win+Alt+K 静音麦克风、Win+Alt+D 隐藏桌面日期时间。

Windows 11 与 Windows 10 的差异

同一个键在 Win10 / Win11 上含义不同，升级后最容易按错的都在这。

Win+Z贴靠布局

Win10 没有；Win11 悬停最大化按钮或按 Win+Z 弹出贴靠布局，可一次选四分屏。

Win+A快速设置

Win10 是操作中心；Win11 变成音量、亮度、Wi-Fi、蓝牙的快速开关面板。

Win+N通知中心

Win11 新增，通知与日历合并显示；Win10 只有操作中心。

Win+W小组件

Win10 是墨迹工作区；Win11 变成小组件面板（天气、新闻等）。

Win+C聊天 / Copilot

Win10 是 Cortana；Win11 随版本变化：聊天、Copilot 或仅打开设置。

Win+Alt+↑/↓贴靠半屏

Win11 新增，直接把窗口贴到上半屏或下半屏，省去两次方向键。

Win+Shift+R区域录屏

Win11 新增，框选区域录屏并自动存成 MP4（视频\屏幕录制）。

PrtScn默认区域截图

Win10 复制全屏到剪贴板；Win11 默认打开区域截图，可在辅助功能里关掉。

资源管理器标签页

Win11 22H2 起资源管理器支持标签页：Ctrl+T 新建、Ctrl+W 关闭、Ctrl+1…9 切换。

Win+Tab任务视图

两代都有，但 Win11 支持把窗口拖到别的虚拟桌面、合并成贴靠组。

开始菜单贴靠布局入口

Win10 只能把窗口拖到屏幕边缘；Win11 悬停最大化按钮即可选布局。

Win+Alt+D/K/V桌面与声音

Win11 新增：隐藏桌面日期时间 / 全局麦克风静音 / 声音输出快速设置。
