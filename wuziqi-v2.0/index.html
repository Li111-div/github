操作教程

从零开始，5 分钟学会局域网联机对战。

0开始之前

  • 准备 两台设备（两台手机、两台电脑，或一手机一电脑均可）。
  • 让它们连接 同一个 Wi-Fi / 路由器。这是能否连上的关键。
  • 各自用浏览器打开本页面，推荐 Chrome 或 Edge。

A房主操作（先手 · 执黑）

  1. 点「创建房间」，进入创建房间页面。
  2. 点「生成邀请码」，下方会出现一段文本，这就是邀请码。
  3. 点「复制邀请码」，然后通过微信 / QQ / 短信把它发给好友。
  4. 等好友回传：好友操作后会生成一段「回传码」发给你，把它粘贴到第 3 步的输入框。
  5. 点「确认连接」，等待 1~3 秒，双方自动进入棋盘。

B挑战者操作（后手 · 执白）

  1. 点「加入房间」，进入加入房间页面。
  2. 粘贴邀请码：把房主发来的邀请码粘到输入框，点「生成回传码」。
  3. 点「复制回传码」，把它发回给房主。
  4. 等待连接：房主点「确认连接」后，你会自动进入棋盘。

C对局操作

  • 落子：点击棋盘的交叉点即可，鼠标悬停会显示预览棋子。
  • 胜负：横、竖、斜任意方向先连成 五子 者获胜。
  • 重新开始：向对手发出请求，对方同意后双方棋盘同时清空，黑方先手。
  • 请求悔棋：撤回双方各一步，同样需要对方同意。
  • 认输：直接判对方获胜。
  • 聊天：左侧聊天面板，打字后按回车或点发送按钮，消息以气泡形式显示；对方发来的在左边，自己发的在右边。

?常见问题

为什么不需要服务器？

本页面使用浏览器内置的 WebRTC 技术，两台设备直接建立点对点（P2P）连接。所谓「邀请码 / 回传码」只是在手动交换建立连接所需的握手信息，相当于把服务器的工作交给了你手里的聊天软件来完成。

一直连不上怎么办？

页面会明确告诉你卡在哪一步，按提示排查即可。常见顺序：① 两台设备是否连在同一个 Wi-Fi；② 邀请码 / 回传码是否完整复制（不要有多余空格或漏字符）；③ 是否中途刷新过页面或重新生成过邀请码（旧的那段码会失效，需要重新走一遍流程）；④ 提示「连接超时」时，多为路由器开启了「AP 隔离」或屏蔽了多播，可尝试关闭该设置，或改用手机热点。

能用手机流量吗？

默认只在局域网内直连，两台设备不在同一网络时无法建立连接。如需跨网络使用，需要在 js/config.js 中填入 STUN / TURN 服务器地址。

会泄露我的隐私吗？

不会。对局数据只在两台设备之间点对点传输，不经过任何第三方服务器，也不会被保存。
