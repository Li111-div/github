    Anime.js 详细介绍

    一个轻量、灵活、易上手的 JavaScript 动画引擎。本文以列表模式整理核心概念、常用 API、示例与性能建议。

    DOMCSSSVGTimelineJavaScript 对象

    01Anime.js 是什么？

    Anime.js 是一个用于创建网页动画的 JavaScript 动画引擎，能够控制 HTML / DOM 元素、CSS 属性、SVG 属性、SVG 路径以及普通 JavaScript 对象。

    • 页面加载动画
    • 按钮悬停和点击效果
    • 卡片、菜单、弹窗动画
    • 滚动触发动画
    • 数字计数和数据可视化
    • SVG 图形绘制与路径运动
    • 文字逐字出现、页面转场和交互式拖拽

    02安装 Anime.js

    npm

    npm install animejs

    ESM 导入

    CDN

  import { animate } from 'https://esm.sh/animejs';
  animate('.box', { x: 300 });
</script>

    03最基本的动画

    import { animate } from 'animejs';

animate('.box', {
  x: 300,
  duration: 1000
});

    基本结构是 animate(目标元素, 动画参数)。上例让元素沿 X 轴移动 300 像素，持续 1000 毫秒。

    04常用动画属性

    位移x: 200, y: 100
    旋转rotate: 360 或 rotate: '1turn'
    缩放scale: 1.5、scaleX、scaleY
    倾斜skewX: 30
    透明度opacity: 0
    CSS 属性backgroundColor、borderRadius、width
    animate('.box', {
  x: 200,
  rotate: 360,
  scale: 1.2,
  opacity: 0.8,
  backgroundColor: '#ff3366',
  borderRadius: '50%',
  duration: 1000
});

    05动画参数

    参数作用示例
    duration持续时间duration: 1000
    delay开始前延迟delay: 500
    ease缓动函数ease: 'outElastic'
    loop循环播放loop: true 或 loop: 3
    alternate往返播放alternate: true
    loopDelay循环间隔loopDelay: 500
    reversed反向播放reversed: true

    常见缓动包括 linear、outQuad、outExpo、outElastic、outBounce。

    06起始值和结束值

    // from / to
animate('.box', {
  x: { from: -300, to: 300 },
  duration: 1200
});

// 数组
animate('.box', {
  opacity: [0, 1],
  scale: [0.5, 1]
});

// 相对值
animate('.box', { x: '+=100' });

    07多个元素与交错动画

    import { animate, stagger } from 'animejs';

animate('.box', {
  x: 300,
  delay: stagger(100),
  duration: 800
});

// 从中间开始
animate('.box', {
  scale: 1.5,
  delay: stagger(100, { from: 'center' })
});

    stagger() 可用于列表逐项出现、菜单展开、图片墙和数据图表。

    08Keyframes：关键帧动画

    animate('.box', {
  keyframes: [
    { x: 100, scale: 1.2, duration: 500 },
    { x: 300, rotate: 180, scale: 1, duration: 800 },
    { x: 0, rotate: 360, duration: 1000 }
  ]
});

    适合实现弹跳、摇摆、入场与出场组合、多阶段交互和复杂运动效果。

    09Timeline：时间轴

    import { createTimeline } from 'animejs';

const timeline = createTimeline();

timeline
  .add('.box', { x: 200, duration: 600 })
  .add('.circle', { scale: 1.5, duration: 500 })
  .add('.title', { opacity: 1, y: 0, duration: 700 });

    可以使用第二个位置参数控制时间：300 表示从第 300 毫秒开始，'-=300' 表示提前 300 毫秒并产生重叠。

    10回调与控制动画

    const animation = animate('.box', {
  x: 300,
  duration: 1000,
  onBegin: () => console.log('开始'),
  onUpdate: animation => console.log(animation.progress),
  onComplete: () => console.log('完成')
});

animation.pause();
animation.play();
animation.restart();
animation.reverse();
animation.seek(500);

    常见回调：onBegin、onUpdate、onRender、onLoop、onComplete。

    11SVG 与 JavaScript 对象

    SVG 路径绘制

    import { animate, svg } from 'animejs';

animate('path', {
  strokeDashoffset: svg.drawLine(),
  duration: 2000
});

    JavaScript 对象与数字计数

    const counter = { value: 0 };

animate(counter, {
  value: 1000,
  duration: 2000,
  ease: 'outExpo',
  onUpdate: () => {
    document.querySelector('#number').textContent =
      Math.round(counter.value);
  }
});

    12Animatable 与 Timer

    鼠标跟随

    import { createAnimatable } from 'animejs';

const box = createAnimatable('.box', {
  x: 400, y: 400,
  duration: 500,
  ease: 'outQuad'
});

document.addEventListener('mousemove', event => {
  box.x(event.clientX);
  box.y(event.clientY);
});

    Timer

    import { createTimer } from 'animejs';

createTimer({
  duration: 3000,
  onUpdate: timer => console.log(timer.currentTime),
  onComplete: () => console.log('计时结束')
});

    13WAAPI 模式

    import { waapi } from 'animejs';

waapi.animate('.box', {
  x: 300,
  opacity: 0.5,
  duration: 1000
});

    WAAPI 模式适合简单、体积敏感的动画；完整 JavaScript 版本更适合时间轴、SVG、对象动画、复杂回调和精细控制。

    15优点与不足

    优点
    • API 简洁，入门成本低
    • 支持 DOM、CSS、SVG 和对象
    • 时间轴和交错动画强大
    • 支持 ESM tree-shaking
    • 适合高质量交互效果
    不足
    • 简单效果用 CSS 可能更直接
    • 复杂 3D 场景不如 Three.js
    • 大型项目需要注意动画清理
    • 大量滤镜、阴影和布局动画可能卡顿

    16性能建议

    1. 优先动画化 transform 和 opacity。
    2. 避免在每次鼠标移动或滚动事件中不断创建新动画。
    3. 连续交互优先考虑 createAnimatable()。
    4. 减少同时执行复杂滤镜、阴影和布局动画的元素数量。
    5. 对不可见元素暂停动画，合理控制循环。
    经验法则：能用 x、y、scale、rotate、opacity 解决时，尽量不要频繁修改布局属性。

    17完整示例：卡片入场动画

    import { animate, stagger } from 'animejs';

animate('.card', {
  opacity: 1,
  y: 0,
  delay: stagger(120),
  duration: 800,
  ease: 'outExpo'
});

    这段代码会让卡片依次从下方移动并淡入，适合页面首屏、列表和内容模块展示。

    18总结

    Anime.js 可以理解为一个用 JavaScript 精确控制 DOM、CSS、SVG 和数据对象动画的轻量级动画引擎。

    • animate()：创建普通动画
    • createTimeline()：组织多个动画
    • stagger()：制作交错动画
    • createAnimatable()：制作持续响应式动画
    • createTimer()：创建计时逻辑
    • svg.createMotionPath()：让元素沿 SVG 路径运动
