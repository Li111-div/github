# 冰箱数字实验室 · THE SCIENCE OF COOLING

一台**广告级 3D 双开门冰箱数字实验室**网页：整机展示 / 门体开合 / 抽屉抽拉 / 爆炸图 / 剖面图 /
密闭制冷循环 / 部件特写，以及一套可交互的双温区热工仿真与教学面板。

> 视觉定位：高端家电广告片 + 工业产品拆解动画 + 数字孪生控制台 + 教学实验室。

---

## 1. 如何打开

**双击 `OPEN_ME.html`** 即可。

* 单文件、自包含：Three.js r147 与全部应用代码已内联，**不依赖任何远程 CDN**，断网可用。
* 在 `file://` 协议下直接打开即可运行，无需本地服务器。
* 建议使用桌面版 Chrome / Edge / 新版 Firefox，窗口 ≥ 1366×768。

如果要做二次开发，用多文件入口 `index.html`（同样的功能，按模块拆成 18 个 `src/*.js`）。

## 4. 六种模式

| 模式 | 内容 |
|---|---|
| **整机 PRODUCT** | 门关闭、产品 3/4 Hero 机位、克制热点标签、广告文案 |
| **开门 OPEN** | 双门绕真实铰链打开（最大 138°，默认开启 116°），箱内照明亮起，可点击抽屉抽拉 |
| **爆炸 EXPLODE** | 每个零件沿合理装配方向分离，0–100% 进度可调；进入前自动收抽屉、关门，并**暂停热工时钟** |
| **剖面 SECTION** | 沿竖直切平面剖开，显示 外层钣金 / 发泡保温 / 内胆 的三明治结构，位置可调；剖切只改变显示，不改变热工模型边界 |
| **回路 CYCLE** | 箱体半隐藏，突出制冷剂管路，粒子按温度区段着色（橙红 → 金黄 → 青蓝 → 青绿） |
| **特写 INSPECT** | 点击部件或右侧「结构」列表，镜头自动重新构图，其他部件降权为半透明剪影 |

### 动作联锁（统一 Kinematics Controller）

* 抽屉拉出前必须先把对应门体打开到安全角 **76°**；
* 关门前必须先收回该侧全部抽屉；
* 进入爆炸图前自动收回全部抽屉并关闭双门；
* 爆炸过程中禁止门 / 抽屉产生操作；
* 所有门架、搁板、抽屉之间保留实际几何净空。

整机共 **79 个独立装配节点**（每个节点拥有自己的 Group / ID，可单独参与爆炸与特写）：

* **箱体结构 16**：左右外壳、顶板、底板、后面板、左右/顶部/底部/后部保温层、左右内胆、中央隔热梁、机械舱框架、机械舱检修盖、隔板、底座与踢脚
* **门体系统 13**：双门体、双门封条、双把手、上下 4 个铰链、门架 ×2、双区数字温控屏
* **内部储物 18**：6 层钢化玻璃搁板、4 个抽屉、搁板承托卡槽、**搁板高度调节槽**、抽屉固定导轨、送风道盖板、顶部风道出口、回风格栅、双区 LED 照明
* **制冷系统 22**：变频压缩机（含半剖外壳、定子、转子、偏心曲柄、连杆、活塞、气缸阀组、减振脚）、丝管式冷凝器、翅片式蒸发器、蒸发器风机、除霜加热管、接水槽、除霜排水管、接水盘、机械舱轴流风扇、过滤干燥器、制冷剂管路系统
* **电气控制 3**：主控 PCB、线束、温度传感器组
* **食材 8**：冷藏搁板 / 冷冻搁板 / 4 个抽屉 / 双门架食材组（共 61 件示意食材、168 个网格）

程序化建模规模：**约 16.9 万个三角形 / 557 个网格**，全部由代码生成，不使用任何外部模型文件。

### 内部储物结构（本轮升级）

* **搁板**：钢化玻璃四周磨边 + 前 / 后铝合金包边 + 前沿微上翘**防溢挡边** + 左右塑料端盖 + **前沿集成 LED 灯带**（为下层食材补光）。
* **抽屉**：前板上沿**一体式铝合金拉手**、前板金属装饰条、两侧**可见三节导轨滑块**、盒体底部加强筋。
* **内胆**：两侧**竖向搁板调节槽**（每 60 mm 一档，共 26 档）+ 每层 4 个承托卡槽，搁板可换位。
* **门架**：加深至 86 mm（可容纳真实尺寸食材），前挡板顶部金属**瓶挡横杆**、底部加强筋、顶部装饰条。
* **风道**：蒸发器舱出风口带层叠导流叶片；背部竖向风道对应每层搁板开设**分层送风口**；回风格栅带防护叶片。

### 建模质量规范

* 圆角：所有家电钣金与塑料件使用 `ExtrudeGeometry + bevel` 或圆角盒，视觉圆角 1–15 mm，不出现锐利 90° 直角。
* 厚度：门体（58 mm 三明治）、玻璃（7 mm）、内胆（6 mm）、外壳（12 mm）、抽屉、PCB、风机叶片均有真实厚度。
* 微小结构：门封凹槽、抽屉三节导轨、搁板卡槽、压缩机减振脚、风机护圈、管路夹、线束固定点。
* 重复零件：冷凝器 64 根竖向散热丝、蒸发器 62 片铝翅片、定子 15 层叠片等全部使用 `InstancedMesh`。

## 6. 材质与灯光

### 材质分层（PBR）

| 部件 | 关键参数 |
|---|---|
| 象牙白珠光门板 | `metalness 0.20 / roughness 0.30 / clearcoat 0.16`，暖白 `#e9e0d0`，叠微颗粒粗糙度贴图 |
| 箱体钣金 | 更冷灰白、更哑光（`roughness 0.40`） |
| 发泡保温层 | 奶黄 `#dccea6`、`roughness 0.95`、闭孔泡沫贴图 |
| ABS 内胆 | 高漫反射、无金属感（`metalness 0.02 / roughness 0.70`） |
| 钢化玻璃 | 有厚度、青灰边缘、`clearcoat 1.0`、`opacity 0.34` |
| 铜管 | 暖铜色 `metalness 0.92 / roughness 0.31`，与铝、普通钢明显区分 |
| 拉丝不锈钢把手 | `metalness 0.94` + 拉丝法线贴图 |
| 压缩机黑烤漆 | `metalness 0.30 / roughness 0.42`，保留环境反射边缘高光，不吸光 |

### 影棚灯光层级

1. 大面积顶部软光箱（主光）
2. 左侧暖色主轮廓光
3. 右后侧冷色 rim light（勾边）
4. 前向柔和补光 + HemisphereLight 基础环境
5. 地面接触阴影 + 径向淡出无限地面
6. 冰箱背部压暗，突出主体轮廓

环境反射由**程序化 PMREM 影棚**生成（7 组大面积发光面），渲染使用 `ACESFilmicToneMapping`，
曝光经标定避免象牙白门板过曝——门板、把手、玻璃、铜管各自保留独立高光特征。
另提供「棚拍：浅色 / 深色」两种影棚背景，一键切换。

## 7. 数字仿真模型

> **教学模拟 · 非实测数据。** 页面顶部与右侧面板均明确标注。

双温区集总参数热模型：

```
dT/dt = (Q_env + Q_door + Q_load − Q_cooling) / C
Q_排 ≈ Q_吸 + P_压缩机
```

| 参数 | 取值（教学标定） |
|---|---|
| 冷藏 / 冷冻热容 C | 12 000 / 9 000 J·K⁻¹ |
| 冷藏 / 冷冻漏热 UA | 1.05 / 0.95 W·K⁻¹ |
| 开门附加 UA | 8.6 W·K⁻¹ |
| 压缩机功率范围 | 3 – 96 W |
| COP | 逆卡诺 × 0.46 降额，随冷凝温度动态变化 |
| 冷凝器 UA | 11.5 W·K⁻¹（正常）/ 3.35 W·K⁻¹（散热受阻） |
| 制冷量分配 | 冷冻 66 % / 冷藏 34 %（单蒸发器 + 风门） |
| 除霜 | 停机 + 180 W 电加热，12 分钟模拟时间 |

**实测行为**（`simtest.js` 纯数值验证，全部无 NaN/Infinity）：

| 场景 | 结果 |
|---|---|
| 散热受阻 15 min | 冷凝温度 33.4 → **53.7 °C**，COP 1.96 → **1.46** |
| 恢复散热 | 冷凝温度回到 33.5 °C，COP 回到 1.96 |
| 断电 1 h | 冷冻室 −17.5 → **−4.4 °C**（+13.6 K），冷藏室 5.8 → 11.0 °C |
| 恢复供电 30 min | 回到 5.83 / −17.49 °C |
| 除霜 6 min | 压缩机停机，蒸发器 −24.9 → **+5.5 °C**，加热功率 180 W |
| 除霜结束 20 min | 回到 5.90 / −18.05 °C |

压缩机负荷按温差比例计算后做指数平滑（τ ≈ 46 s），**不会从 0 瞬间跳到 100 %**。

## 8. 三套流场可视化（互相严格区分）

| 可视化 | 表达 | 颜色 |
|---|---|---|
| **箱内空气循环** | 细半透明曲线 + 粒子，从风道送出、沿搁板横向流动、经回风格栅返回 | 青蓝 |
| **密闭制冷剂循环** | 粒子沿**真实铜管曲线**运动，按温度区段着色 | 橙红 → 金黄 → 青蓝 → 青绿 |
| **向室内排热** | 冷凝器背面稀疏暖色粒子向上漂移 + 热流线 + 轻辉光，强度随 `heatRejection` 与 `condenserTemp` 变化 | 暖橙 |

粒子使用自定义 ShaderMaterial（逐粒子颜色 + 逐粒子透明度），在浅色与深色影棚下都成立。

## 9. 食材系统

箱内共 **61 件程序化建模食材**，分布在冷藏搁板 / 冷冻搁板 / 4 个抽屉 / 两侧门架：

| 位置 | 食材 |
|---|---|
| 冷藏搁板 | 牛奶盒 · 易拉罐 · 塑料瓶 · 酸奶杯 · 保鲜盒 · 苹果 / 橙子 / 柠檬 · 番茄 · 肉类托盘 |
| 冷藏抽屉 | 生菜 · 西兰花 · 胡萝卜 · 苹果 / 橙子 / 柠檬 |
| 冷冻搁板 | 冰淇淋桶 · 速冻袋装 · 披萨盒 · 肉类托盘 · 冷冻盒 |
| 冷冻抽屉 | 速冻袋装 · 肉类托盘 · 冰淇淋桶 |
| 门架 | 牛奶 · 饮料瓶 · 易拉罐 · 6 枚装蛋架 · 调味瓶 · 保鲜盒 · 速冻小包装 |

**食材不是装饰，它们真的参与物理：**

* 右侧「**显示食材**」开关控制显隐；
* 「**食材装载量**」滑块同时决定 **3D 中显示多少食材** 与 **箱内有效热容**；
* 食材挂在真实承托物上——抽屉食材随抽屉抽拉、门架食材随门体旋转，**不穿模**（由  逐件校验）；
* 实测对比（同样开门 1 分钟）：

| 装载量 | 食材质量 | 有效热容 C | 冷藏升温 | 冷冻升温 |
|---|---|---|---|---|
| 空箱 | 0 kg | 9.0 / 7.0 kJ/K | +1.07 °C | +2.86 °C |
| 常规 65 % | 5.5 kg | 18.8 / 13.8 kJ/K | +0.54 °C | +1.51 °C |
| 满仓 100 % | 8.5 kg | 24.0 / 17.5 kJ/K | +0.42 °C | +1.20 °C |

结论：**食材越多，温度越稳，但降温也越慢**——这就是「装满的冰箱比空冰箱更抗折腾」的原因。

## 12. 真实性边界

* 外观为**高端双门家用冰箱概念设计**，不是任何品牌具体产品的 1:1 CAD 复刻，未使用任何受保护造型或 Logo。
* 温度、功率、COP、能耗均为**教学仿真参数**，用于说明物理趋势，不代表真实机型实测数据。
* 空气流线**不是 CFD 求解结果**。
* 压缩机内部动画是**原理教学慢动作**，不代表真实转速（UI 已标注）。
* 所有几何、纹理、环境贴图均为程序化生成，不含任何第三方模型或图片素材。
* 模型结构保留统一 metadata 接口，可后续替换为真实测量数据或更高级求解器。

## 13. 性能

* 重复件全部 `InstancedMesh`；相同材质复用；贴图尺寸克制。
* 阴影只给唯一主光（2048² 贴图，PCFSoft），其余光源不投影。
* 箱内点光源使用 `decay = 1`（`decay = 2` 在 0.4 m 处会产生约 6 倍过曝）；箱内材质 IBL 强度压到 0.2–0.4，
  让内部明暗由箱内光源决定，而不是无遮挡的环境光——这是「冰箱内部一片白」的根因。
* 粒子数量固定并按模式动态调整透明度；`devicePixelRatio` 上限 2。
* 单次绘制约 557 个网格 / 16.9 万三角形。
