# 网站使用说明

阜阳职业技术学校官方网站 · 纯静态站点（HTML + CSS + 原生 JS），无构建、无依赖，双击即可打开。

主题：淡蓝色系（湖蓝 `#2378B6` + 浅蓝底 `#F6FAFE`），全站共享一套设计变量，另用少量朱红 `#C0392F` 作点缀。

---

## 一、本地预览

**方式一（推荐，视频与字体加载更稳）**

在本目录打开终端，任选其一：

```bash
python -m http.server 8080
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

**方式二**

直接双击 `index.html`。功能均可用，部分浏览器在 `file://` 下会限制视频自动播放，点一下播放按钮即可。

> 站内搜索、新闻详情弹窗、常见问题折叠、资料下载均为原生 JS 实现，`file://` 下同样可用。

---

## 二、部署

把整个文件夹上传到任意静态服务器 / 对象存储 / CDN 即可（Nginx、Apache、OSS、COS、GitHub Pages 均可）。所有资源均为相对路径，放在子目录（如 `/site/`）也能正常访问。

- 首页文件：`index.html`
- 不需要 Node 环境、不需要数据库。
- PDF 文件较大（合计约 15MB），如使用对象存储建议开启分片上传与 CDN 加速。

## 四、新增功能说明

### 4.1 站内搜索

- 页头放大镜按钮、移动端抽屉搜索入口均可打开
- 快捷键：`/`（非输入框状态）或 `Ctrl/Cmd + K`
- 索引覆盖：10 个页面、18 个专业、9 条新闻、4 条常见问题、3 个下载文件
- 支持空格分词、标题优先排序、关键词高亮、回车直达首个结果
- 索引数据在 `js/main.js` 第 15 节：`SEARCH_PAGES / SEARCH_MAJORS / SEARCH_NEWS / SEARCH_FAQ / SEARCH_FILES`
- 新增内容时，在对应数组里补一条即可（`t` 标题、`d` 描述、`u` 链接、`k` 关键词、`type` 类型）

### 4.2 新闻动态

- `news.html` 内置 9 条示例稿件，5 个分类（校园要闻 / 教学教研 / 德育天地 / 招生就业 / 通知公告）
- 分类筛选带滑块指示器，右上角实时显示“共 N 条”
- 点击卡片打开详情弹窗，支持 Esc 关闭、点击遮罩关闭，关闭后焦点回到原卡片
- 新闻正文存于 `news.html` 底部 `<script type="application/json" id="newsData">`，结构为：

```json
{
  "n1": {
    "cat": "校园要闻", "date": "2026-02-24", "dept": "办公室",
    "img": "images/gate-aerial.jpg", "title": "标题",
    "lead": "导语", "body": ["正文段落 1", "正文段落 2"], "sign": "落款"
  }
}
```

- 新增一条新闻：复制 JSON 里的一项改 `id`，再复制一张卡片改 `data-news="nX"` 与 `data-cat` 即可
- 首页“校园新鲜事”为 3 条静态预览卡，需手动同步

### 4.3 常见问题

- `faq.html` 共 10 条，同一时间只展开一项（互斥手风琴）
- 首项默认展开，`aria-expanded` 随状态同步
- 答案依据 2024 年质量年报与公开招生信息整理，页内已注明“以教育主管部门和学校正式发布为准”

### 4.4 资料下载

- `downloads.html` 提供 3 份 PDF：质量年度报告（2024 年）、省赛获奖名单（学生赛 / 教师赛）
- 链接带 `download` 属性，移动端浏览器可直接预览
- 文件放在 `files/`，替换同名文件即可更新，无需改代码

### 4.5 页面级小细节

- 新闻页、师资页、常见问题页、资料下载页均有页头统计条（`phead__stats`）
- FAQ 与下载页右侧为粘性侧栏（宽屏 `position:sticky`，窄屏自动转静态）

## 五、常见修改

### 5.1 改主色调

打开 `css/style.css` 顶部 `:root`：

```css
--brand:      #2378B6;  /* 主色：湖蓝（按钮/链接/强调） */
--brand-deep: #1B639A;  /* 主色加深（hover） */
--brand-ink:  #1D6396;  /* 深色文字用蓝 */
--brand-soft: #E1EFFA;  /* 浅蓝底（标签/图标底） */
--brand-tint: #EEF6FC;  /* 更浅的蓝（区块底） */
--accent:     #3AA6C9;  /* 辅助色：青蓝（数字/渐变） */
--bg:         #F6FAFE;  /* 页面底色 */
--bg-tint:    #EAF3FB;  /* 备用底色 */
--surface-dark:#102338; /* 深色 CTA / 页脚 */
/* 点缀红：只做少量强调，不影响蓝色主调 */
--hot:        #C0392F;  /* 红色主色（荣誉数字/圆点/眉标短线） */
--hot-ink:    #A02C24;  /* 红色文字用深红 */
--hot-soft:   #FBEBE9;  /* 红色浅底（新闻卡标签 hover） */
--hot-lite:   #EE7E6B;  /* 深色区块上的亮红（CTA 眉标） */
```

改这几个值即可整体换肤，其余颜色（线条、阴影、遮罩）均由它们派生。
注意 `rgba(35,120,182,…)` 形式的半透明色需一并替换，可用编辑器的全局替换。

**红色只出现在这几处**，改 `--hot` 一个值即可统一调整：

| 位置 | 说明 |
|---|---|
| 各区块英文眉标前的短线 | `.eyebrow::before`，22×2px 朱红短线（深色 CTA 上用 `--hot-lite`） |
| 首页「1958 建校年份」照片徽章 | `.intro__badge`，红底白色数字 |
| 首页荣誉数字（3 项 / 33 项 / 特等奖…） | `.awards__list b` |
| 新闻卡左上角分类标签前的小圆点 | `.ncard__badge::before`，悬停时标签转红底 |
| 站内搜索「热门：」字样 | `.search__hot>span` |
| 首屏「2026 招生进行中」呼吸圆点 | `.art__pill i` + `@keyframes liveDot` |

> 若想让红色更弱，把 `--hot` 改成更浅的砖红（如 `#D2604F`）即可；不建议再加入大面积的红色色块。

### 5.2 按钮动效

| 效果 | 触发 | 实现位置 |
|---|---|---|
| 扫光 | `.btn--primary` / `.btn--ghost` 悬停 | CSS 第 37.3 节 `::before` 位移 |
| 箭头右移 | `.btn` 悬停时内部 SVG | `.btn:hover>svg` |
| 涟漪 | 按下（`pointerdown`） | `js/main.js` 第 19 节 + `.ripple` |
| 脉冲光圈 | 页头“招生咨询”按钮常驻 | `@keyframes ctaPulse` |

`prefers-reduced-motion: reduce` 下，扫光、涟漪、脉冲全部关闭。

### 5.3 换校徽

校徽出现在三处：页头品牌位（40px）、移动端抽屉顶部、页脚品牌位（44px）。三处共用同一张图：

```
images/logo.png              256×256 透明 PNG，页头/抽屉/页脚
images/favicon.png            64×64  浏览器标签图标
images/apple-touch-icon.png  180×180 iOS 主屏图标（不透明底色）
```

**直接替换图片**：把新校徽导出成正方形 PNG（建议 256×256 或更大，背景透明），覆盖 `images/logo.png` 即可，无需改代码。

**如果新图是白底 JPG**：先用任意工具抠成圆形透明 PNG，或按 `docs/asset-map.md`「校徽」一节的方法处理（按圆形蒙版裁剪），否则页头会出现白色方块。

**改尺寸**：`css/style.css` 中 `.brand__mark`（默认 40×40，640px 以下 34×34）与 `.ftr__brand .brand__mark`（44×44）。

### 5.4 换图片

图片按用途命名（如 `gate-aerial.jpg`、`cnc-shop.jpg`），直接覆盖同名文件即可，无需改代码。建议宽度不超过 2000px、体积控制在 400KB 以内。

对应关系见 `docs/asset-map.md`。

### 5.5 换视频

视频通过 `data-video="videos/xxx.mp4"` 挂载，点击封面后**原位播放**（不弹层），替换同名文件即可。

### 5.6 留言表单

当前为前端演示（提交后仅提示致电）。正式启用需接入后端，两种简单方案：

1. 表单服务（如金数据、腾讯问卷、Formspree）：把 `<form>` 的 `action` 改成服务地址、`method="post"`，并删除 `js/main.js` 中第 12 节（表单校验）的 `preventDefault` 逻辑。
2. 自有接口：在 `js/main.js` 第 12 节把提示逻辑换成 `fetch()` 提交。

### 5.7 地图

`contact.html` 中的位置图为**自制示意图**（SVG，非精确比例），下方按钮跳转高德地图搜索。

如需嵌入真实地图：在高德开放平台申请 Key，用「地图组件」生成 iframe，替换 `<div class="map-card">` 内的 `<svg>` 即可。

### 5.8 增加一个页面

1. 复制任一页面 → 改 `<title>`、`<meta name="description">`、`<h1>`、正文
2. 在 10 个页面的 `<nav class="nav">` 与 `.drawer__nav` 中同步加链接（页头页脚为各页内联，改一处需同步其余页）
3. 在 `js/main.js` 第 15 节 `SEARCH_PAGES` 里补一条搜索索引
4. 在 `sitemap` 或页脚常用入口中补链接（如需）

## 六、已做的兼容与优化

- 响应式断点：1280 / 1080 / 980 / 640 / 420 / 360px
  - 1280px：隐藏品牌英文小字、压缩导航间距
  - 1080px：隐藏页头搜索按钮、师资卡转 2 列
  - 980px：切换为抽屉导航、新闻卡转 2 列、侧栏取消粘性
  - 640px：单列布局、缩小品牌与页头按钮、隐藏按钮内箭头
  - 360px：隐藏页头招生按钮，仅保留汉堡菜单
- 图片全部压缩，图集与卡片图 `loading="lazy"`
- 视频按需加载，不自动播放
- 无 JS 时内容仍完整可见（`<noscript>` 兜底）
- 支持 `prefers-reduced-motion`，关闭入场、扫光、涟漪、脉冲、「招生进行中」呼吸圆点等动画
- 键盘可用：搜索 `/`、`Ctrl/Cmd+K`、Esc 关闭浮层；灯箱左右键翻页
- 弹窗与抽屉打开时锁定 body 滚动，关闭后恢复焦点

## 七、上线前建议

1. 用学校正式招生简章替换 `admission.html` 中的流程与材料清单表述
2. 把 `news.html` 的 9 条示例稿件替换为真实新闻（页内已注明“示例稿件”）
3. 补充护理、导游服务专业的实训照片（现为文字卡）
4. 核对 `downloads.html` 三份 PDF 是否为最新版本，特别是质量年报的年度
5. 如已备案，补充 ICP 备案号到页脚
6. 接入真实的留言后端或直接移除表单
7. 上传时可不带 `assets-source/` 目录（77.8MB 原始素材，站点运行不需要），能显著减小体积
