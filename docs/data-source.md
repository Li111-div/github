## 十一、口径与风险处理

1. **统一采用质量年报口径**。政府网页旧简介（教职工 164 人、投资 5.4 亿元、校舍近 14 万㎡、设备 4000 余万元）为早年内容，未随扩建更新，站内不采用。
2. **不采用 `fyvtc.edu.cn` 相关内容**——那是阜阳职业技术学院（高职），与本中职无关；素材中一段宣传片因水印为该学院已剔除。
3. **不采用旧站/自媒体数据**（如"95% 就业率""双师型 60%""去年 500 分""中考 450 分不收"）。
4. 每页页脚固定声明数据来源与统计周期。
5. 招生流程、材料清单为通用表述，页面标注"以当年招生简章为准"；如学校提供正式简章，建议替换为原文。
