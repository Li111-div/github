01

MUI 框架详细介绍

MUI 是 DCloud 生态中常见的移动端 UI 框架，常用于 HBuilder / HBuilderX 创建的 HTML5+ App，也就是常说的 5+App 项目。它主要负责移动端页面的布局、组件样式和常用交互。

在 5+App 中，MUI 通常和 HTML5+ API 配合使用：MUI 负责页面好不好看、交互顺不顺；HTML5+ API 负责调用手机原生能力，例如相机、定位、扫码、文件、Webview、原生弹窗等。

5+App 容器让 HTML/CSS/JS 页面以 App 形式运行
+
MUI 框架提供移动端 UI 组件和交互
+
HTML5+ API调用原生能力，如扫码、相机、定位
  • 定位：面向移动端 WebApp / 5+App 的前端 UI 与交互框架。
  • 组成：主要包含 mui.css、mui.js，以及 picker、dtpicker、poppicker、pullRefresh 等扩展文件。
  • 适合：移动端页面、课程项目、简单业务 App、新闻资讯、商城、生活服务、个人中心等。
  • 注意：DCloud MUI 不是 React 的 Material UI，二者不是同一个框架。
02

MUI 的优点与缺点

优点

  • 上手快，会 HTML、CSS、JavaScript 就能写页面。
  • 移动端组件完整，按钮、导航、列表、弹窗、轮播、刷新都有。
  • 适合 5+App，和 plusready、plus.webview 等原生能力配合自然。
  • 不强制依赖 Vue、React，普通静态页面也能直接使用。
  • 默认样式接近移动 App，适合快速完成原型和课程项目。

缺点

  • 整体技术比较老，新项目现在更常用 uni-app、Vue、Vant 等方案。
  • 大型项目中，原生 JS 写法维护成本会逐渐升高。
  • 默认视觉风格偏传统，如果想要现代风格，需要自己重写 CSS。
  • 部分扩展组件需要单独引入对应 CSS 和 JS 文件。
  • 与复杂工程化、组件化开发相比，组织代码的能力较弱。

HBuilder 快速输入方法汇总

快速输入也可以理解为 HBuilder / HBuilderX 里的代码块提示。通常在 HTML、CSS 或 JS 文件中输入快捷词，按 Tab 或 回车，即可快速生成对应的 MUI 组件结构或常用语句。

不同 HBuilder 版本、插件配置或代码块库可能略有差异。如果某个快捷词没有弹出，可以手动输入对应 MUI 类名或语句，本手册仍可作为组件结构参考。

总结

一句话总结：MUI 是 5+App 中常用的移动端 UI 框架，适合快速制作 App 风格页面；它负责界面和交互，HTML5+ API 负责调用手机原生能力。

学习时建议按这个顺序掌握：先会 顶部栏、内容区、底部栏，再会 列表、按钮、表单、弹窗，最后掌握 下拉刷新、轮播图、选择器、Webview 与 plusready。

如果是课程或比赛项目，MUI 的优势是“搭得快、改得快、手机端效果明显”；如果是长期商业项目，则建议结合 Vue / uni-app 等更现代的方案。
