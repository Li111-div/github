先记住 5 条设计逻辑

HBuilderX 的原则是「不定义记不住的快捷键」，记住下面几条规律，大部分键位都能推出来。

1界面键都跟 Alt 走

把键盘当屏幕：左上 Q 项目管理器、W 大纲、右上 P 预览、底部 X/C 控制台与终端，N 回编辑器。

2Ctrl 是操作，Ctrl+Shift 是反向

Ctrl+W 关闭当前 / Ctrl+Shift+W 全部关闭；Ctrl+K 格式化 / Ctrl+Shift+K 合并行。

3再进一步用 Ctrl+Alt

Ctrl+F 本文档查找 / Ctrl+Alt+F 目录内查找；Ctrl+E 选相同词 / Ctrl+Alt+E 选全部相同词。

4贴着系统和浏览器习惯

标签卡管理跟浏览器一致：Ctrl+T 新建、Ctrl+Shift+T 恢复、Ctrl+PgUp/PgDn 切换，找文件是 Ctrl+P 而不是 Eclipse 的快捷键。

5符号优先于字母

Ctrl+= 放大选区、Alt+= 展开、Alt+- 折叠、Alt+[ 跳括号、Ctrl+↑/↓ 移动行。

常见冲突与自定义

装完 HBuilderX 键位不生效，八成是被输入法或常驻软件抢了。

快捷键冲突方处理
Ctrl+Shift+E搜狗输入法全局占用在输入法设置里取消该全局快捷键
Ctrl+Shift+F搜狗输入法（简繁切换）同上；本版该键默认是「区域内查找」
Ctrl+Alt+V印象笔记 Evernote取消印象笔记的全局粘贴
F12部分笔记本 / 浏览器Alt+D 与它等价，冲突时用 Alt+D

自定义位置：%APPDATA%\HBuilder X\user\keybindings.json，左侧默认、右侧自定义，右侧覆盖左侧；冲突时弹菜单，加 "override": true 可强制覆盖；支持连续快捷键，如 "key": "ctrl+1 2"。也可以直接用 Ctrl+Alt+, 打开设置。
